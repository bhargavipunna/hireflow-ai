# AI Job Agent

An Agentic AI system that automatically matches a candidate's resume with relevant jobs, generates ATS-optimized resumes, and prepares for automated job applications.

## Features

### Resume Intelligence

* Resume PDF ingestion
* ChromaDB vector database
* Semantic retrieval using embeddings
* RAG-powered resume understanding

### Job Matching

* Job collection pipeline
* Resume-job similarity scoring
* Ranking and filtering

### Resume Optimization

* Qwen3-powered resume tailoring
* ATS-focused keyword optimization
* Job-specific resume generation

### Agent Architecture

* LangGraph workflow orchestration
* Profile Agent
* Scraper Agent
* Matcher Agent
* Resume Agent

## Tech Stack

### AI

* Qwen3 8B
* Sentence Transformers
* ChromaDB
* LangGraph

### Backend

* Python
* Ollama

### Storage

* JSON
* Chroma Vector Database

## Workflow

Resume PDF
→ RAG Ingestion
→ ChromaDB
→ Job Collection
→ Semantic Matching
→ Resume Tailoring
→ Generated Resume
